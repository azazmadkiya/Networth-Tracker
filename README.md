## ✨ Features

- **📊 Comprehensive Asset & Liability Tracking:**
  - Bank accounts, Fixed Deposits, Cash wallets
  - Mutual funds, Stocks, Gold, Real Estate
  - Personal loans, Credit cards, and Custom liabilities

- **👥 Multi-Profile & Family Allocations:**
  - Track assets under Self, Father, Mother, or Family Joint buckets.

- **🔒 Privacy-First Architecture:**
  - 100% offline local SQLite / Room database.
  - Zero cloud telemetry, zero remote trackers, zero analytics SDKs.
  - PIN and biometric lock protection.

- **💾 Self-Custody Backup & Restore:**
  - One-tap encrypted JSON export and import.
